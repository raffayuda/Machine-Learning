PENJELASAN LENGKAP KODE DAN OUTPUT UNTUK LAPORAN EARTHQUAKE DBSCAN
=====================================================================

BAGIAN 5.4: KONVERSI KE GEODATAFRAME
-------------------------------------
Penjelasan Kode:
- Point(xy): Membuat objek geometri Point dari pasangan koordinat longitude-latitude
- zip(): Menggabungkan longitude dan latitude secara berpasangan
- gpd.GeoDataFrame(): Membuat GeoDataFrame yang merupakan ekstensi pandas DataFrame dengan kemampuan geospasial
- crs='EPSG:4326': Menetapkan Coordinate Reference System sebagai WGS84 (standar GPS)
- GeoDataFrame memungkinkan operasi geospasial seperti plot peta, perhitungan jarak, dan spatial join

Output:
GeoDataFrame berhasil dibuat!
CRS: EPSG:4326
Bounds: [-179.9892  -54.8453   179.8958   71.3435]

Interpretasi: GeoDataFrame berhasil dibuat dengan CRS WGS84. Bounds menampilkan extent geografis data (longitude: -179.99 hingga 179.90, latitude: -54.85 hingga 71.34), menunjukkan cakupan global.


BAGIAN 5.5: PETA DENGAN BASEMAP
--------------------------------
Penjelasan Kode:
- gdf.plot(): Membuat plot dari GeoDataFrame
- column='Earthquake Magnitude': Mewarnai points berdasarkan nilai magnitude
- cmap='YlOrRd': Colormap kuning-oranye-merah (magnitude rendah ke tinggi)
- alpha=0.6: Transparansi 60% agar overlap points terlihat
- ctx.add_basemap(): Menambahkan peta dasar dari CartoDB Positron untuk konteks geografis
- Basemap membantu identifikasi lokasi geografis dengan menampilkan batas negara dan fitur geografis

Output Visual:
Peta global menampilkan sebaran 16,946 gempa bumi dengan points berwarna sesuai magnitude. Warna kuning menunjukkan magnitude rendah, oranye magnitude menengah, dan merah magnitude tinggi. Terlihat konsentrasi gempa di Ring of Fire (Pasifik), zona subduksi Indonesia-Filipina-Jepang, patahan San Andreas, dan zona seismik Mediterania. Basemap CartoDB Positron memberikan konteks geografis dengan menampilkan garis pantai dan batas negara.


BAGIAN 5.6: HEATMAP DENGAN FOLIUM
----------------------------------
Penjelasan Kode:
- folium.Map(): Membuat peta interaktif berbasis Leaflet.js
- center_lat, center_lon: Menghitung rata-rata koordinat untuk pusat peta
- zoom_start=2: Level zoom awal untuk tampilan global
- HeatMap(): Membuat layer heatmap yang menunjukkan densitas gempa
- radius=8: Radius pengaruh setiap point dalam pixels
- blur=15: Tingkat blur untuk smooth transition antar densitas
- gradient: Warna gradient dari biru (densitas rendah) hingga merah (densitas tinggi)
- Peta interaktif memungkinkan zoom dan pan untuk eksplorasi detail

Output Visual:
Peta interaktif global dengan layer heatmap menunjukkan konsentrasi densitas gempa bumi. Warna biru menandakan zona dengan sedikit gempa, hijau-kuning zona dengan densitas sedang, dan oranye-merah zona dengan densitas sangat tinggi. Terlihat jelas hotspot di sepanjang Ring of Fire, terutama di Indonesia, Filipina, Jepang, Chili, dan Alaska. Peta dapat di-zoom dan di-pan untuk melihat detail region tertentu. User dapat mengeklik area untuk mendapat informasi lebih detail.


BAGIAN 5.7: EKSTRAKSI DAN NORMALISASI FITUR
--------------------------------------------
Penjelasan Kode:
- .values: Mengkonversi DataFrame kolom menjadi numpy array
- StandardScaler(): Melakukan standardisasi dengan formula: z = (x - μ) / σ
- Normalisasi penting untuk DBSCAN karena:
  * Algoritma menggunakan jarak Euclidean yang sensitif terhadap skala
  * Latitude (-90 hingga 90) dan Longitude (-180 hingga 180) memiliki range berbeda
  * Setelah normalisasi, mean = 0 dan std = 1 untuk setiap fitur
- Normalisasi memastikan kedua fitur memiliki kontribusi yang seimbang

Output:
Shape data koordinat: (16946, 2)
Mean: [-2.22044605e-16  0.00000000e+00]
Std: [1. 1.]

Interpretasi: 16,946 data points dengan 2 fitur (Latitude, Longitude). Setelah normalisasi, mean mendekati 0 (nilai scientific notation sangat kecil) dan standard deviation = 1, membuktikan standardisasi berhasil dilakukan dengan benar.


BAGIAN 6: K-DISTANCE GRAPH
---------------------------
Penjelasan Kode:
- min_samples = 2 × dimensi: Rule of thumb untuk data 2D, hasilnya 4
- NearestNeighbors: Mencari k tetangga terdekat untuk setiap point
- kneighbors(): Menghitung jarak ke k-nearest neighbors
- distances[:, -1]: Mengambil jarak ke tetangga terjauh (k-th neighbor)
- np.sort(): Mengurutkan jarak dari kecil ke besar
- K-distance graph menampilkan jarak sorted untuk menentukan eps optimal
- Eps optimal berada di "elbow point" - titik di mana kurva mulai naik tajam
- Garis horizontal menandai kandidat nilai eps berdasarkan visual grafik

Output:
Min samples yang disarankan: 4

Output Visual:
K-distance graph menampilkan kurva yang awalnya landai kemudian naik tajam. Pada awal grafik (points dengan banyak tetangga dekat), jarak rendah. Kemudian kurva mulai naik secara gradual, dan akhirnya naik tajam (points yang terisolasi). Elbow point terlihat sekitar 0.10-0.20. Garis merah (eps = 0.15) dan oranye (eps = 0.20) menandai kandidat nilai eps yang reasonable. Nilai 0.15 dipilih karena berada di knee of curve, memberikan keseimbangan antara jumlah cluster dan noise.


BAGIAN 7: IMPLEMENTASI DBSCAN
------------------------------
Penjelasan Kode:
- eps=0.15: Radius maksimum neighborhood (dari K-distance graph)
- min_samples=5: Jumlah minimum points dalam eps untuk core point (disesuaikan dari 4 menjadi 5 untuk reduce noise)
- metric='euclidean': Menggunakan jarak Euclidean untuk perhitungan similarity
- fit_predict(): Melakukan clustering dan mengembalikan label cluster
- Label -1 menandakan noise/outlier points
- Label 0, 1, 2, ... menandakan cluster yang berbeda
- set(clusters): Mendapatkan unique cluster IDs
- Hasil disimpan kembali ke DataFrame dan GeoDataFrame untuk analisis lanjutan

Output:
Jumlah cluster: 47
Jumlah noise points: 3891
Persentase noise: 22.96%

Interpretasi: DBSCAN berhasil mengidentifikasi 47 cluster yang merepresentasikan zona seismik aktif di berbagai belahan dunia. Terdapat 3,891 noise points (22.96%) yang merupakan gempa terisolasi atau berada jauh dari zona seismik utama. Persentase noise yang moderat (~23%) menunjukkan parameter eps dan min_samples sudah cukup optimal - tidak terlalu banyak noise (eps terlalu kecil) dan tidak terlalu sedikit cluster (eps terlalu besar).


BAGIAN 8: EVALUASI CLUSTERING
------------------------------
Penjelasan Kode:
- mask = clusters != -1: Membuat boolean mask untuk filter noise points
- Evaluasi hanya dilakukan pada cluster (tanpa noise) untuk hasil yang valid
- Silhouette Score: Mengukur seberapa mirip object dengan cluster-nya sendiri vs cluster tetangga. Range [-1, 1], semakin tinggi semakin baik.
- Davies-Bouldin Index: Mengukur rata-rata similarity antar cluster. Semakin rendah semakin baik (cluster lebih terpisah).
- Calinski-Harabasz Score: Ratio between-cluster variance dan within-cluster variance. Semakin tinggi semakin baik (cluster compact dan terpisah).
- Ketiga metrik memberikan perspektif berbeda tentang kualitas clustering

Output:
Jumlah cluster untuk evaluasi: 47

Silhouette Score: 0.4527
Davies-Bouldin Index: 0.8934
Calinski-Harabasz Score: 3842.7156

Interpretasi:
- Silhouette Score 0.4527: Nilai positif dan mendekati 0.5 menunjukkan clustering cukup baik. Points lebih dekat dengan cluster-nya sendiri dibanding cluster lain. Nilai ini acceptable untuk data geospasial yang kompleks.
- Davies-Bouldin 0.8934: Nilai < 1 menunjukkan clustering baik dengan separasi antar cluster yang jelas. Semakin rendah semakin baik, nilai 0.89 menunjukkan cluster relatif well-separated.
- Calinski-Harabasz 3842.72: Nilai tinggi menunjukkan cluster yang compact dan well-separated. Nilai ribuan menunjukkan variance between-cluster jauh lebih besar dari within-cluster.

Secara keseluruhan, ketiga metrik menunjukkan bahwa DBSCAN berhasil membentuk cluster yang berkualitas baik dengan separasi yang jelas antar zona seismik.
